O Luma é um aplicativo desenvolvido com Flutter, pensado para oferecer uma experiência moderna, intuitiva e agradável de biblioteca digital. O projeto utiliza uma identidade visual própria, com tons escuros e detalhes em roxo, priorizando uma interface elegante e uma navegação simples.

🚧 Status do projeto: Em desenvolvimento.

# ✨ Funcionalidades

🎨 Splash Screen personalizada: tela inicial com a identidade visual do Luma.

💜 Identidade visual própria: interface com tema escuro e detalhes em roxo.

📚 Tela de biblioteca: estrutura inicial para a experiência principal do aplicativo.

⚡ Transição automática: navegação da tela inicial para a biblioteca.

📱 Interface multiplataforma: desenvolvido com Flutter para facilitar a criação de aplicativos para diferentes plataformas.

As funcionalidades serão ampliadas conforme o desenvolvimento do projeto.

# 🛠️ Tecnologias utilizadas

Flutter — framework para desenvolvimento multiplataforma.

Dart — linguagem de programação utilizada pelo Flutter.

Material Design — componentes e recursos para construção da interface.

Git e GitHub — controle de versão e hospedagem do código.

# 🚀 Como executar o projeto

Pré-requisitos

Antes de começar, instale e configure:

Flutter SDK

Dart SDK — normalmente incluído no Flutter.

Um editor de código, como Visual Studio Code.

Um dispositivo ou emulador compatível.

1. Clone o repositório

git clone URL_DO_SEU_REPOSITORIO

2. Entre na pasta do projeto

cd luma_app

3. Instale as dependências

flutter pub get

4. Verifique o ambiente Flutter

flutter doctor

5. Execute o aplicativo

flutter run
